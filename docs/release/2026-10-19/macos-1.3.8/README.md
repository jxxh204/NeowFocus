# macOS 1.3.8 공개 출시 준비 — 2026-10-19

사용자가 TestFlight의 PC 1.3.8을 App Store 공개 출시하도록 요청했다. 업로드·처리 완료·현재 테스터 계정 설치 가능 상태는 이전 기록에서 검증됐다. 재빌드는 필요 없다.

공개 심사 제출을 위해 App Store Connect를 확인했으나 이메일 입력 로그인 화면(authResult=FAILED)이 표시된다. 사용자에게 재로그인을 요청했고, 현재 공개 심사 상태·스토어 버전·빌드 연결은 변경하지 않았다. iOS도 변경하지 않았다. 공개 심사는 아직 제출하지 않았다.
