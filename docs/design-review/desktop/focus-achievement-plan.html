집중을 지킨다

할 일 하나로 시작합니다. 진행 중에는 남은 시간을 숨기고 게이지만 보여줍니다. 방해 요소를 차단해 작업으로 돌아오도록 돕습니다.

집중을 성취로 남긴다

태스크는 업무의 완성이 아니라 사용자가 마친 한 번의 집중입니다. 정한 시간이 끝나거나 직접 마치면 발도장 하나를 줍니다.

PC가 작업을 지키고, 앱이 그 집중을 이어줍니다.

같은 정보를 모든 화면에 복제하지 않습니다. PC는 작업 곁에 조용히 머물고, 모바일은 시작과 조작을 쉽게 만듭니다.

집중 중기존 작은 창에 할 일과 게이지만 표시. 남은 숫자·상시 연결 안내·성과 표시는 숨깁니다.할 일, 고양이, 큰 원형 게이지. 하단 왼쪽 ‘잠시 멈춤’, 오른쪽 ‘마침’.
일시정지게이지가 멈추고 고양이 상태가 바뀝니다. 재개와 마침을 선택합니다.같은 화면에서 왼쪽 버튼만 ‘다시 집중’으로 바뀝니다. 남은 숫자는 계속 숨깁니다.
완료짧은 발도장 연출 후 오늘 쌓인 집중을 보여줍니다. 차단을 해제하고 작업을 가리는 팝업은 최소화합니다.발도장과 ‘집중 하나가 쌓였어요.’를 표시합니다. 실제 집중 시간은 작게 보여주고 차단을 해제합니다.

잠금화면과 위젯

잠금화면: 고양이·게이지 중심. 할 일은 기존 공개 설정을 따릅니다. 남은 숫자는 숨깁니다.

위젯: 대기 중에는 오늘의 발도장과 시작 진입점, 집중 중에는 현재 할 일과 게이지를 보여줍니다.

모바일 링 두께 22·바늘 길이 55%는 유지합니다. PC와 작은 표면은 각 크기에 맞는 비율을 사용합니다.

페이지를 이동하지 않고 상태가 바뀝니다.

첫 안내 → 준비 → 집중 → 성취

오른쪽 시안에서 흐름을 체험하세요. ‘마침’과 시간 종료 모두 같은 발도장을 받습니다. 시안은 실제 시간 경과를 측정하지 않으며, 시간 종료 버튼으로 완료 상태를 확인합니다.

  • 시작 전: 시간 선택이 보입니다.
  • 진행 중: 숫자 없이 할 일과 게이지만 남습니다.
  • 완료 후: 실제 집중 시간을 확인합니다.
  • 다음 준비: 오늘 쌓인 발도장을 보여줍니다.

긴 온보딩, 반복되는 브랜드명, 종료 직전 깜빡임은 넣지 않습니다. 설정과 기록은 필요할 때만 여는 보조 화면입니다.

오늘의 집중을 모아, 편하게 마무리합니다.

이번 기획 포함 완료 화면에서 ‘오늘은 여기까지’를 선택하면 오늘의 성취를 보여줍니다. 매번 자동으로 띄우지 않습니다.

오늘도 집중을 쌓았어요.

발도장은 횟수와 관계없이 하나만 크게 표시합니다. 누적 성취는 ‘11번의 집중’처럼 숫자로 표현하고, 실제 집중 시간과 했던 일은 작게 보여줍니다. 목표 미달·어제와의 비교·순위는 넣지 않습니다.

모바일은 같은 화면에서 전환합니다. PC는 기존 창을 잠시 넓혀 보여주되 전체 화면을 덮지 않습니다. 하단 왼쪽 ‘계속하기’는 같은 작업과 직전 시간을 채운 준비 화면으로 돌아갑니다. 자동 시작하지 않습니다. 오른쪽 ‘오늘 마무리’는 휴식 상태로 돌아갑니다. 어느 쪽을 선택해도 기록은 유지하고, 다음 집중은 오늘 기록에 이어 쌓입니다.

기록은 잠그지 않습니다. 같은 집중은 기기 간 한 번만 집계하고 현재 기기의 날짜와 완료 시각으로 오늘을 구분합니다.

두 가지 성취 연출

마침·시간 종료: 발도장이 꾹 찍히고 살짝 튕기는 0.6초 연출. 앱에서는 진동 설정이 켜진 경우 가볍게 한 번 울립니다.

오늘은 여기까지: 고양이의 상체가 화면 위에서 내려옵니다. 얼굴 없이 등과 머리 뒤쪽, 앞발만 보입니다. 앞발로 중앙 도장을 찍을 때마다 집중 횟수가 올라가고, 마지막에는 다시 화면 위로 올라가 사라집니다. 발도장은 하나만 남습니다. 약 3초 안팎으로 재생하며, 30회를 넘는 경우 일부 숫자를 묶어 올린 뒤 정확한 총횟수를 표시합니다. 추가 진동은 없습니다.

두 연출 모두 진입할 때 한 번만 재생하며 버튼은 즉시 누를 수 있습니다. HTML은 화면 연출만 시연하며 기기 진동은 재현하지 않습니다.

발도장은 완료 횟수, 시간은 들인 노력을 보여줍니다. 순위·연속 기록 상실 경고·짧은 집중 감점은 넣지 않습니다. 기존의 ‘1분 미만 기록 제외’ 규칙도 새 완료 기준에 맞춰 제거해야 합니다.

완료 소리·진동은 기본 켜짐이며 사용자가 직접 끈 선택을 유지합니다. 기기 무음·알림 설정을 따르고, 동작 줄이기 설정에서는 완료 연출을 단순화합니다.

차단은 선택한 집중을 보호합니다.

이번 기획 확정 차단할 앱과 사이트는 사용자가 직접 선택합니다. 집중 중에는 선택한 대상만 차단하며, ‘마침’을 누르면 즉시 해제합니다. 이 기능을 이번 구현 범위에 포함합니다.

PC: 방해 사이트 진입 차단

차단할 사이트는 사용자가 직접 선택합니다. 집중을 시작하면 선택한 사이트를 차단하고, ‘마침’을 누르거나 집중 시간이 종료되면 해제합니다. 업무에 필요한 사이트는 차단 대상으로 선택하지 않을 수 있습니다.

시작 전 습관적 접속은 타이머만으로 해결되지 않습니다. 미리 정한 업무 시간부터 차단하는 방식은 별도 선택 기능 후보입니다.

앱: 폰으로 옮겨가는 이탈 차단

차단할 앱은 사용자가 직접 선택합니다. 집중을 시작하면 선택한 앱을 차단하고, ‘마침’을 누르거나 집중 시간이 종료되면 해제합니다. 배포 권한과 동작 가능 범위를 확인해 적용합니다.

‘마침’은 집중 완료로 인정하여 발도장을 주고 차단도 해제합니다. 별도의 해제 대기 시간이나 불이익은 두지 않습니다. 일시정지 중 차단 유지 여부는 아직 결정하지 않았습니다.

구현 전 확인: PC 브라우저별 차단 방식·권한, iOS 배포 권한, 오프라인 동작, 일시정지 중 차단 정책과 긴급 해제. 사용자 선택·집중 중 차단·마침 시 해제는 확정 사항이며, 현재 시안은 실제 차단 구현을 의미하지 않습니다.

별도 서버를 쓰지 않는 기존 방향은 유지합니다. 동기화와 잠금화면 반영은 플랫폼 제약을 따릅니다. PC에서 시작한 집중을 잠긴 iPhone에 항상 새로 띄우는 동작은 보장하지 않습니다.

먼저 집중과 성취의 흐름을 완성합니다.

  1. 시안 검토: 첫 안내, 숫자 없는 집중, 발도장 완료, 한번 더, 오늘 성취.
  2. PC·앱 적용: 기존 디자인 유지, 수동 완료와 짧은 집중의 보상·기록 기준 통일.
  3. 잠금화면·위젯 적용: 숫자 숨김, 상태·게이지 반영, 할 일 공개 설정 유지.
  4. 실기기 검증: 기기 간 중복 없는 완료, 일시정지 시간 제외, 완료 소리·진동, 접근성.
  5. 차단 구현 — 이번 범위: 사용자 대상 선택 → 집중 시작 시 차단 → 마침 또는 시간 종료 시 해제. 플랫폼 권한과 오프라인·동기화 동작을 검증하고, 일시정지 정책은 추가 확정.

사용성 테스트에서 확인할 것

  • 업무가 남아 있어도 집중 하나는 완료됐다는 의미를 이해하는가?
  • 시간 숫자가 없어도 편안하게 집중 상태를 이해하는가?
  • 직접 마친 경우에도 성취감을 느끼는가?
  • 다음 집중을 시작하기 쉽고, 다른 콘텐츠로 새는 순간이 줄었는가?

앱을 오래 보는 것보다 실제 작업에 머무르고, 마친 집중을 자기 성취로 느끼는 것이 성공 기준입니다.
