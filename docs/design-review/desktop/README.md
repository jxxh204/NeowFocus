# PC UI 재검토 — 2026-10-13

사용자 요청: 이번 PC 업데이트에서 새로 추가한 UI를 모두 제거하고, 기존 디자인을 기준으로 다시 설계하여 검토받는다. 승인 전 PC 새 UI 적용·배포 금지.

## 제거 완료 (소스 기준)

- 상단 연결 확인 문구
- 연결 설정의 기본 체크박스 및 기술 오류 원문
- 입력창의 추가 추천 행과 숫자 입력
- 기록 화면의 임시 삭제 안내
- 임시 충돌 팝업

기존 input/settings/dashboard 표현으로 되돌렸으며 동기화 상태·저장·마이그레이션 로직과 기능 버그 수정은 유지했다. 사용자 기존 변경 파일(useLocalStorage 등)은 건드리지 않았다. 검토 전 소스는 새 연결 설정/충돌 선택 UI가 빠진 중간 상태이므로 배포하지 않는다. 설치된 1.3.1에는 아직 이전 UI가 남아 있다.

## 시안

`index.html` / http://127.0.0.1:8770/

기존 402px 폭, 차콜, 기존 고양이 자산, 흰 타이머 유지. 집중 화면은 연결 오류에 의해 변하지 않는다. 설정은 468px 높이, 구분선과 여백으로 연결/시간/테마 구분, 네이티브 느낌의 스위치. 연결 오류는 설정 안에 짧게 표시. 직접 입력·삭제 취소·충돌 선택까지 6개 상태를 검토할 수 있다. 외부 좌측 탐색은 검토 도구이며 앱 UI가 아니다. 토글/시간/색 클릭은 로컬 시연만 하며 실제 계정이나 기록을 변경하지 않는다.

## 확인된 실제 동기화 오류

설치된 NeowFocus의 CloudKit 로그에서 아래 원인 확인:

`Cannot create new type NeowFocusState in production schema`

대상: iCloud.com.neowfocus.pomodorotimer / private default zone / record type NeowFocusState / record ID focus-state-v1 / field json (String).

출시 환경 스키마 미배포가 원인이다. 사용자 iCloud 설정 문제라고 안내하지 않는다. CloudKit Console 로그인 요청 상태이며 개발 스키마 확인 후 프로덕션 배포가 필요하다. cktool 관리 토큰도 현재 없어 CLI로 처리하지 못했다. 비밀값을 채팅에 요청하지 않는다. 원인 확인만 완료됐고 서버 수정·동기화 성공은 아직 아니다.

## 검토 결과 — 2026-10-14

사용자가 디자인 방향을 승인했다. 단, PC 첫 작업 제안은 제거 요청했다. PC는 입력 후 바로 시작하는 흐름으로 유지한다. 시안의 제안 행과 PC 컨텍스트의 제안 전용 API를 제거했다. 모바일의 제안 기능 및 공통 동기화 데이터는 유지한다. 나머지 승인 UI 적용과 배포 검증은 후속 진행한다.

승인 방향 소스 적용 완료: 설정 토글/높이, 삭제 취소 행, 본문 충돌 선택. PC 추천은 제외. 33개 테스트와 타입 검사 통과, 실제 renderer 오류 상태 본문 높이/내용 높이 동일(438px) 확인. 1.3.2 TestFlight 업로드 완료(00:19 KST). CloudKit 출시 스키마 배포 후 설치된 1.3.1 연결 정상 확인.
