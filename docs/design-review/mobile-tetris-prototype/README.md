# 집중 테마 — 모바일 프로토타입

2026-10-22 사용자 결정: 원형 타이머 아래에 블록을 더하는 방식은 제외한다. **기존 원형·화면 전체 블록·화면 전체 물 채우기**를 독립된 테마로 나누고 설정에서 바꾼다. 이 폴더는 실제 앱에 적용하지 않은 별도 HTML 시안이다.

## 실행

저장소 루트에서:

```sh
python3 docs/design-review/mobile-tetris-prototype/serve.py
```

- 기본/블록: `http://127.0.0.1:8782/?theme=blocks`
- 물: `http://127.0.0.1:8782/?theme=water`
- 기존 원형: `http://127.0.0.1:8782/?theme=classic`

`index.html`을 직접 열어도 동작한다. 외부 라이브러리·계정·실제 타이머 데이터는 쓰지 않는다. 예전 `?variant=A|B|C` 링크는 이제 기본 블록 테마로 열린다.

## 설정 흐름

오른쪽 위 설정 → 집중 테마에서 세 가지 중 하나 선택 → 완료. 진행률·일시정지·완료 상태가 그대로 유지된다. ‘남은 시간 표시’도 설정 안에서 켤 수 있다. Escape로 닫을 수 있고 키보드 포커스는 열린 설정 안에 머문다.

시안의 테마 선택은 메모리에만 유지된다. URL에는 선택한 테마가 반영되지만 앱 설정에 저장하지 않는다. 실제 구현에서 기기별 사용자 설정으로 저장할지·기기 간 동기화할지는 아직 구현하지 않았다.

## 세 테마

| 테마 | 집중 중 | 완료 시 |
| --- | --- | --- |
| 기존 원형 | 현재 앱의 원형 타이머, 차콜 바탕 | 기존 원본 발도장 |
| 쌓이는 블록 | 원형 없이 화면 가장자리까지 테트로미노 누적 | 화면 전체가 쌓인 블록으로 채워짐 + 원본 발도장 |
| 차오르는 물 | 원형 없이 화면 전체 너비의 물이 아래에서 위로 상승 | 화면 꼭대기까지 물이 차오름 + 원본 발도장 |

블록과 물은 헤더·작업명·버튼 뒤를 포함한 **화면 전체**를 사용한다. 텍스트·설정·집중 액션은 전경에 남는다. 완료 뒤에도 채워진 화면을 유지하며 ‘한번 더’에서 비운다. 게임 조작·점수·줄 삭제·실패는 없다.

## 모션과 샘플 조작

- 25분 샘플을 절반 진행한 일시정지 상태로 연다. ‘25분 빠르게 보기’는 처음부터 60배로 재생해 25초에 전체 과정을 보여준다. 10배/실제 속도도 가능하다.
- 시작·절반·완료 프리셋과 시간 슬라이더로 누적 상태를 바로 확인한다. 이 조작은 시안 밖에 있다.
- 블록: 진행률에 맞춰 72개/288칸을 채운다. 12×24 보드의 4×4 구역을 물리적으로 낙하 가능한 테트로미노 패턴으로 채우므로 마지막에 구멍이 남지 않는다. 블록은 약 620ms 낙하, 착지 강조는 820ms 안에 종료한다. ‘블록 하나 쌓기’는 다음 블록만 확인한다.
- 물: 높이 = 경과 시간 / 계획 시간. 얕은 두 물결을 합쳐 잔잔하게 흔들고, 최종 높이에서는 화면 끝까지 채운다. ‘1분 채우기’로 높이를 이동한다.
- 일시정지하면 새 블록·물 높이·물결이 멈춘다. 이미 낙하 중인 블록은 착지를 마친다. 화면이 숨겨지면 시안 시간과 모션을 멈춘다.
- 시스템 Reduce Motion 또는 ‘낙하·물결 동작 줄이기’가 켜져 있으면 낙하 대신 즉시 누적하고 물결은 평평하게 표시한다.

## 검증과 범위

- 기본 브라우저 폭 및 390×844에서 설정 선택·닫기, 테마 전환 후 50% 유지, 원형 표시/숨김, 남은 시간 토글, 시작/절반/완료, 모션 줄이기를 확인했다.
- 블록 72개가 288칸을 중복·범위 이탈 없이 모두 채우는 것을 확인했다. 실제 브라우저에서 블록과 물 100%가 화면 전체를 채운 모습도 확인했다.
- 원본 발도장 SVG는 현재 앱의 파일을 그대로 사용한다. 실제 제품의 소스·설정·타이머·기록·빌드·출시는 변경하지 않았다.
- 기계적 UI 검사 경고 1건: phone 컨테이너에 하단 안쪽 여백이 없다는 경고. 화면 전체를 채워야 한다는 사용자 요청에 따른 의도된 캔버스 배치다. 텍스트와 조작 버튼에는 별도 안쪽 여백을 유지한다.
- 별도 자동 테스트는 추가하지 않았다. 웹 시안 검증이며 React Native 구현·실기기 성능·배터리·백그라운드 복원 검증을 대신하지 않는다.
