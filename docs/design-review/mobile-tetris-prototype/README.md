# 쌓이는 집중 — 모바일 모션 프로토타입

2026-10-22 사용자 요청: 모바일에서 시간이 흐를수록 테트리스 모양 블록이 쌓이는 모션을 시안으로 확인한다. **실제 앱에 적용하지 않은 별도 HTML 시안**이다.

## 실행

저장소 루트에서:

```sh
python3 docs/design-review/mobile-tetris-prototype/serve.py
```

`http://127.0.0.1:8782/?variant=A`를 연다. 서버 없이 `index.html`을 직접 열어도 동작한다. 라이브러리 설치·계정·저장소 연결은 없다.

## 확인할 질문

지나간 시간을 블록으로 남기는 것이 집중의 성취감을 돕는가? 기존 원형 타이머와 함께 있어도 시선을 지나치게 끌지 않는가?

| 안 | 배치 | 비교할 지점 |
| --- | --- | --- |
| A | 기존 원형 타이머 아래 작은 누적 보드 | 기존 디자인에 가장 작게 더할 수 있다. 우선 추천하는 안이며 사용자 선택은 아직 없다. |
| B | 원형 타이머 대신 큰 블록 보드 | ‘남은 시간’ 대신 ‘쌓인 집중’을 중심에 둔다. |
| C | 기존 타이머 뒤 은은한 배경 | 진행 중에는 약하게, 완료 시에는 쌓인 블록을 작은 결과물로 보여준다. |

하단 화살표 또는 키보드 좌우로 바꾼다. `?variant=A`, `B`, `C`로 직접 열 수 있다. 안을 바꿔도 샘플 시간·일시정지 상태는 유지된다.

## 모션 가설과 조작

- 샘플 집중 25분, 1분마다 테트로미노 1개. 실제 적용 시 이 간격은 아직 미정이다.
- 기본 재생은 60배: 실제 1초에 샘플 1분이 흐른다. 10배/실제 속도도 선택 가능하다.
- 블록은 650ms에 걸쳐 낙하하고, 180ms 안에 착지 강조가 사라진다. 줄 삭제·조작·점수·실패는 없다.
- ‘1분 쌓기’는 다음 블록만 확인한다. 슬라이더는 누적 상태를 바로 탐색한다. ‘처음부터’는 자동 재생을 다시 시작한다.
- 앱 안의 ‘잠시 멈춤’/‘다시 집중’은 샘플 시간 흐름을 멈추거나 재개한다. 이미 낙하 중인 블록은 착지를 마친다. 화면이 숨겨져 있을 때 시간과 모션은 진행하지 않는다.
- ‘마침’과 25분 자동 완료는 기존 원본 발도장을 보여준다. 완료 뒤 블록을 지우지 않으며 ‘한번 더’에서 새로 시작한다.
- 시스템의 `prefers-reduced-motion` 또는 ‘낙하 동작 줄이기’가 켜져 있으면 낙하 대신 누적 결과가 바로 나타난다.
- 남은 시간 숫자는 현재 앱처럼 기본 숨김이며 시안 컨트롤에서 켤 수 있다.

## 기존 디자인과 검증

기준: `apps/mobile/src/app/index.tsx`, `components/CircularTimer.tsx`, `theme.ts`. 차콜 `#272727`, 흰 원형 타이머, 작업명 우선, 기존 고양이·발도장·액션을 이어받았다. 조작용 컨트롤과 하단 시안 선택기는 앱 디자인 밖에 둔다.

- 브라우저 기본 폭과 390×844 모바일 폭에서 확인했다. A/B/C 전환, 일시정지, 1분 쌓기, 시간 이동, 숫자 토글, 모션 줄이기, 완료 원본 발도장을 확인했다.
- 세 보드 모두 25개/100칸이 범위 안에 쌓이는 것을 확인했다. 행은 삭제하지 않는다.
- 기계적 UI 검사 결과 지적 없음. 별도 자동 테스트는 추가하지 않았다.
