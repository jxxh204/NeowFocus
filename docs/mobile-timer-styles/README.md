# 모바일 타이머 스타일

2026-10-22 승인된 HTML 시안(`docs/design-review/mobile-tetris-prototype`, fb36d5d)을 React Native 모바일 앱에 반영한다. PC 소스와 디자인은 변경하지 않는다.

## 사용자 동작

- 설정 → **타이머 스타일**에서 기존 원형 / 쌓이는 블록 / 차오르는 물을 선택한다.
- 썸네일, 설명, 우측 라디오와 **남은 시간 표시** 체크박스, 완료 버튼을 사용한다. 기존 집중 시간·알림·자동 휴식·iCloud·개인정보 설정은 아래에 유지한다.
- 실행 중 화면을 탭하면 반투명 바텀시트에 **잠시 멈춤(또는 다시 집중)**, **마침**만 나타난다. 바깥 탭과 시스템 닫기로 해제한다.
- 스타일을 바꾸거나 설정을 닫아도 현재 집중 시간, 일시정지 상태, 기록은 유지된다. 스타일과 남은 시간 표시 여부는 기기에 저장한다. 기존 설치는 원형 / 남은 시간 숨김으로 시작한다.
- 블록과 물은 안전 영역을 포함한 전체 화면을 채운다. 두 스타일에는 원형 타이머를 표시하지 않는다.

## 표현과 상태

- 블록: 승인 시안의 12×24 보드, 72개 테트로미노를 그대로 사용한다. 진행률로 배치를 복구하며 정상 진행 중 새 블록 한 개에만 낙하/착지 모션을 적용한다. 재시작·스타일 전환·백그라운드 복귀로 여러 개가 증가하면 과거 모션을 재생하지 않는다.
- 물: 승인 시안의 두 겹 파형, 청회색 그라데이션, 고정 위상 속도 **4.32rad/s**를 그대로 사용한다. 사실적 물 재질·고양이 오리배 실험은 포함하지 않는다.
- 애니메이션은 해당 컴포넌트 안에서 최대 30fps로 갱신한다. 세션 시계와 저장소에 애니메이션 프레임을 쓰지 않는다. 일시정지, 설정 표시, 앱 백그라운드에서 모션을 멈춘다. 동작 줄이기 설정은 평평한 수면과 정적 블록으로 처리한다.
- 수동 마침은 실제 집중한 비율을 유지한다. 자연 완료는 화면을 채운다. 기존 완료 발자국, 오늘 마무리 고양이, 자동 휴식과 동기화 흐름을 사용한다.

## 검증

- `pnpm --filter @neowfocus/mobile typecheck`
- `pnpm --filter @neowfocus/mobile test:timer-styles`: 기존 설정 복원, 모든 스타일 값, 72개 블록의 충돌 없는 낙하 및 288셀 완전 채움, 진행률 복원, 물 높이/고정 속도/동작 줄이기.
- `pnpm --filter @neowfocus/core test`: 타이머·기록·휴식·동기화 회귀 79개.
- `node apps/mobile/scripts/check-completion-geometry.cjs`: 기존 발자국과 8방향 고양이 기하 검증 48개.

## iOS 화면 검증 (2026-10-22)

- iPhone 18 Pro / iOS 27 Simulator에서 실제 React Native 화면을 검증했다. 기존 시뮬레이터 앱 런타임 복사본에 이 소스에서 생성한 새 iOS 번들을 넣어 설치했다. 최종 번들은 Hermes bytecode v98이다.
- 설정 썸네일·라디오·시간 표시 체크박스·완료 버튼, 세 스타일 전환, 전체 화면 채움과 두 버튼만 있는 반투명 바텀시트를 확인했다.
- 1분 세션의 자연 완료와 기존 발자국/기록 흐름을 확인했다.
- 5분 세션을 일시정지한 뒤 물 → 블록 → 원형으로 바꿔도 **04:44 / 6% / 잠시 멈춤**을 유지했다. 블록 상태에서 앱을 종료/재실행한 뒤에도 같은 값이 복원됐다. 다시 집중과 시간 숨김을 확인했다.
- 물 배경 위 완료 화면 보조 글자의 대비를 보완했다. 최종 번들에서 수동 마침을 실행해 실제 집중한 비율(약 49%)의 물 높이가 유지되고 기존 완료 화면으로 전환되는 것을 확인했다.
- iPad는 현재 앱 설정 `supportsTablet: false`이므로 대상에 포함하지 않았다. 실물 기기 테스트는 수행하지 않았다.
- 전체 시뮬레이터 네이티브 재컴파일은 컴파일 자원 부담으로 중단했다. **새 네이티브 빌드 성공/배포 완료를 뜻하지 않는다.** 소스 타입 검사와 새 번들의 iOS 런타임 검증을 완료한 단계이며, 배포용 재빌드와 TestFlight/App Store 업로드는 별도 단계다.
