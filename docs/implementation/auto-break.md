# 자동 10분 휴식 — 2026-10-15

PC와 모바일의 설정에 **집중 후 10분 휴식** 토글을 추가했다. 신규 설치와 설정 값이 없는 기존 설치 모두 기본 `false`이며, 기기별로 보관한다. CloudKit 집중 기록에는 휴식을 넣지 않는다.

## 동작

- 설정을 켠 뒤 집중 시간이 다 되거나 사용자가 마치면 그 완료 시각부터 10분간 자동 휴식한다.
- 완료 화면의 기존 발자국을 유지하고 휴식 남은 분/초와 **휴식 끝내기**를 표시한다. 2026-10-16 PC 디자인 복원 후 PC는 기존 가로 배치와 초록색 발자국이다. 오늘 성취·하루 마무리 고양이는 모바일에만 있다.
- 휴식은 집중 시간·기록·도장 수에 포함하지 않는다. Chrome 차단과 모바일 집중 제한은 기존 집중 완료 상태에 따라 풀린다.
- 10분 후에는 ‘휴식이 끝났어요.’와 다시 준비하는 버튼을 표시한다. 다음 집중을 자동 시작하지 않는다.
- 휴식 끝내기나 설정 끄기로 현재 휴식을 끝낸다. 모바일에서는 ‘오늘은 여기까지’로 하루 요약을 선택해도 휴식을 끝낸다. PC에는 하루 마무리 기능이 없다. 건너뛴 휴식은 재실행이나 설정을 다시 켰을 때 재시작하지 않는다.
- 설정을 켜는 순간 이미 완료된 작업에는 휴식을 새로 붙이지 않는다. 다음 완료부터 적용한다.
- 휴식 종료 시각을 따로 보관한다. 새로 열거나 절전·백그라운드에서 돌아오면 원래 완료 시각으로 남은 시간을 계산하며 10분을 새로 주지 않는다. 앱을 닫은 사이 집중이 끝났어도 원래 휴식에서 남은 시간만 표시한다.
- 충돌 해결로 종료된 작업에는 휴식을 시작하지 않는다. 휴식 완료 알림이나 휴식용 잠금화면/Live Activity는 추가하지 않았다.

## 구현 위치

- 공통 정책: `packages/core/src/break.ts`. 실제 `finishedAt + 600000`과 건너뛰기 표식을 복원한다.
- PC: `TaskContext`, `SettingsContext`, 완료 화면·설정. `neowfocus.break.v1`과 `appSettings.autoBreak`에 저장. 설정 창은 오류 안내 상태에서도 아래 버튼이 잘리지 않도록 402×630으로 조정했다.
- 모바일: `FocusProvider`, `SettingsProvider`, `storage`, 완료 화면·설정 패널. AsyncStorage `neowfocus.break.v1`에 보관. 휴식 상태는 공유 집중 세션을 변형하지 않는다.

## 검증

- core/PC/모바일 전체 타입 검사 통과.
- PC Jest 43 tests 통과. 기본 꺼짐, 자동/수동 완료, 10분 종료, 집중 기록 유지, 건너뛰기 재실행, 절전/시계 지연, 앱이 닫힌 동안의 집중 종료, 설정 나중 켜기/끄기 포함.
- 공통 Vitest 79 tests 통과. 새 휴식 정책 3 tests 포함.
- PC production renderer 및 모바일 Expo web export 통과.
- 실제 renderer/모바일 웹 미리보기에서 기본 꺼짐 → 설정 켜기 → 집중 시작 → 수동 완료 → 10:00 휴식 → 재실행 후 남은 시간 유지 → 중간 종료 확인. 모바일은 중간 종료 후 새로 열어도 완료 화면만 표시됨을 확인했다.
- PC 설정은 iCloud 오류 안내를 함께 표시해도 본문 600px 안에 하단 메뉴가 들어간다. 좁은 390px 미리보기에서도 확인했다.
- 변경 UI detector 결과 항목 없음.
- Mac 앱/실제 iPhone에서의 동작은 아직 미확인. 새 TestFlight 업로드는 하지 않았다.

PC 1.3.5와 모바일 0.1.0(8) 모두 업로드는 Xcode Apple 계정 인증 오류로 중단됐다. 기존 TestFlight iOS 0.1.0(7)에는 이 휴식 기능이 포함되지 않는다. [iOS 배포 상태](../../apps/mobile/scripts/RELEASE-STATUS.md).
