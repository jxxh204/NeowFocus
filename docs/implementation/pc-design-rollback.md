# PC 디자인 복원 — 2026-10-16

사용자 요청: “pc버전 디자인 변경된거 되돌려줘”, “오늘은 여기까지는 pc에 없던거야”. 이 결정이 이전 PC 집중·성취 기획과 구현 기록보다 우선한다.

## 현재 PC 범위

- 기존 입력창·집중창 크기와 가로 배치, 타이머의 남은 시간 숫자, 작은 창 버튼을 복원했다.
- 첫 안내, 입력창의 새 시간 선택·오늘 집중 횟수 문구, 별도의 하루 휴식 안내를 제거했다.
- 일반 완료는 기존 크기의 초록색 배경·원래 발자국과 새 작업/반복 버튼 두 개다. 일반 완료 발자국은 정지 상태로 유지한다.
- **PC에는 ‘오늘은 여기까지’, 하루 요약, 픽셀 고양이·발도장이 없다.** 해당 route, 컴포넌트, 전용 집계 API, 설정 플래그, 이미지와 전용 검증 스크립트를 앱 소스에서 제거했다. 모바일의 하루 마무리는 유지한다.
- 설정의 기존 카드, 시간 선택 버튼, 색상 선택 디자인을 복원했다. 요청된 iCloud·Chrome 연결, 완료 소리·진동, 기본 꺼짐인 자동 10분 휴식은 유지한다. 추가 설정을 담을 높이는 확보했다.
- 반복 준비·공통 기록·동기화·Chrome 연결 로직과 저장 데이터는 유지했다. 설정에서 기본 시간을 바꾸면 입력 준비 시간도 함께 바뀐다.

## 검증

- 전체 workspace 타입 검사 통과.
- PC Jest 6 suites / 43 tests 통과. 로컬 포트가 필요한 기존 Chrome 연결 테스트는 sandbox 밖에서 실행했다.
- production renderer/main/preload 빌드 통과. 최종 renderer에 PC 하루 마무리 문자열·경로·픽셀 이미지가 남지 않음을 확인했다.
- 실제 Electron Mac 창에서 입력 → 집중 → 수동 완료, 기존 발도장/두 버튼, 반복 준비, 자동 휴식 설정 기본 false → 켜기 → 완료 즉시 10:00을 확인했다. 첫 테스트의 완료 기록이 재실행 후 유지됨도 확인했다.
- UI 검증은 `NEOWFOCUS_TEST_USER_DATA=/private/tmp/neowfocus-pc-design-rollback-20261016`의 분리된 임시 기록을 사용했다. 설치된 사용자 앱·기록은 교체하거나 초기화하지 않았다.
- 증거: `evidence/pc-design-rollback/input.png`, `focus.png`, `completed.png`, `settings.png`, `break.png`.
- 변경 전 UI/제거 파일의 복구 사본은 `apps/desktop/build-output/pc-design-before-rollback-20261016/`에 있다. 앱 소스나 배포 자산으로 포함하지 않는다.

## 출시 상태

App Store Connect의 Mac 소개·업데이트·심사 메모에서도 하루 마무리/픽셀 고양이/시간 숫자 숨김 설명을 제거해 초안으로 저장했다. 실제 저장값은 `../release/2026-10-16/macos-store-metadata-after-rollback.json`이다.

기존 1.3.5 아카이브는 이 수정이 없으므로 공개 심사에 사용하지 않는다. 사용자의 최신 출시 승인 후 수정본 1.3.6을 새로 패키징·서명하고 실제 아카이브의 PC 하루 마무리/첫 안내/픽셀 자산 미포함을 확인했다. Xcode Organizer 업로드 및 Apple 처리를 마쳤고 21:02 KST 공개 심사 제출 완료 / 심사 대기 중이다. 승인 후 자동 출시 설정이며 현재 사용자 설치 앱 업데이트 완료를 의미하지 않는다. 상세는 [출시 기록](../release/2026-10-16/README.md)을 따른다.
