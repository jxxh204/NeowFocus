# 현재 상태 — 2026-10-20

현재 작업 브랜치는 `feat/mobile-monorepo`다. 이 스냅샷은 PC·모바일·공통 코어 구현, Chrome 확장, 네이티브 모듈·위젯, 이미지·검토 시안, 빌드/배포 스크립트, 날짜별 출시 기록을 함께 보존한다.

## 구현·출시

- PC: 기존 디자인·완료 발자국을 유지하며 완료 버튼은 ‘다른 작업’/‘계속하기’다. ‘오늘은 여기까지’와 고양이 연출은 모바일에만 있다.
- PC 1.3.8: Dock 아이콘을 유지하는 native panel로 다른 앱의 전체 화면 위에 표시한다. 이전 1.3.7과 렌더러 해시가 같고 실제 Mac 개발 실행을 검증했다.
- 모바일: 하루 마무리에만 8방향 픽셀 고양이·픽셀 발도장을 사용한다. 일반 집중 완료는 기존 발자국이다.
- 자동 10분 휴식은 PC·모바일 모두 기본 꺼짐이며 설정에서 켤 수 있다. 선택형 private CloudKit 동기화와 충돌 처리, Chrome 연결 및 위젯 관련 소스를 포함한다.
- iOS 심사 2.5.1 대응으로 불필요한 Screen Time API를 제거했다. iOS 0.1.0(12) 및 PC 1.3.7 공개 심사는 10월 18일 확인 당시 심사 대기였고 현재 상태는 재확인 전이다.
- PC **1.3.8(1.3.8)**은 10월 18일 TestFlight 업로드 성공, 10월 19일 실제 Mac TestFlight에서 ‘업데이트’ 버튼을 확인했다. [증거](../release/2026-10-18/testflight-1.3.8/README.md).
- PC 1.3.8 공개 App Store 심사는 **App Store Connect 웹 로그인 대기**다. 아직 새 공개 심사를 제출하지 않았다. [재개할 작업과 제출 내용](../release/2026-10-19/macos-1.3.8/README.md).

날짜별 문서에는 당시 시도·제한·미완료 상태가 남아 있다. 최신 상태는 이 문서와 위 링크를 우선한다. TestFlight 설치 가능 확인을 새 빌드 설치·실행 검증이나 공개 출시 완료로 해석하지 않는다.

## 이번 동기화 검증

- `pnpm run typecheck`: 공통 코어·PC·모바일 통과.
- `pnpm --filter @neowfocus/core test`: 8 files / 79 tests 통과.
- `pnpm --filter neow-focus-vite exec jest --runInBand`: 6 suites / 43 tests 통과. 초기 샌드박스의 루프백 포트 제한으로 Chrome 연결 테스트가 실패해, 포트 접근이 가능한 환경에서 같은 테스트를 다시 실행했다.
- 추가·변경 파일의 비밀 키 패턴 검사에서 일치 없음. 이 검사가 완전한 보안 감사를 의미하지는 않는다.

## 로컬에만 보존하는 파일

인증서·개인 키·환경 변수·프로비저닝 프로파일·빌드 산출물·캐시·업로드 로그는 Git에 포함하지 않는다. 기존에 추적되던 `apps/desktop/build/NeowFocus_Mac_App_Store.provisionprofile`은 파일을 로컬에 보존하고 추적만 해제했다. 과거 커밋 이력은 변경하지 않았다. 서명·업로드에는 해당 팀의 인증서와 프로파일을 로컬에서 준비해야 한다. 앱 아카이브는 `apps/*/build-output/`에 보관하며, 공개 가능한 검사 결과·스크린샷·인수인계는 `docs/`에 포함한다.
