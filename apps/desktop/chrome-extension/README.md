# NeowFocus Chrome 연결 (0.1.0)

Mac 앱 1.3.4와 Chrome 120 이상용 로컬 개발 확장입니다. Chrome 웹 스토어에는 게시하지 않았습니다.

## 설치와 연결

1. Mac 앱 설정 → **집중 중 사이트 차단** → **Chrome 확장 폴더 열기**.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 이 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 풉니다.
3. Mac 앱에서 차단할 사이트를 한 줄에 하나씩 입력하고 **저장하고 차단 켜기**를 누릅니다. 최대 30개, http/https 도메인과 하위 도메인에 적용됩니다.
4. Mac 앱의 **Chrome 연결 코드 복사**를 누르고 확장 팝업에 붙여넣어 연결합니다. 코드는 이 Mac의 앱과 확장 사이에서만 사용합니다.
5. 확장의 **선택한 사이트 접근 허용**을 누르고 Chrome이 표시한 사이트 권한을 확인합니다. 허용한 사이트만 차단됩니다. 새 사이트를 추가하면 해당 사이트 권한도 별도로 허용합니다.
6. 집중을 시작해 선택 사이트와 기존 열린 탭이 차단 안내로 바뀌는지 확인합니다. 일시정지·마침 시 차단이 해제됩니다. 원래 열린 페이지는 자동 복원하지 않습니다.

확장 설치와 사이트 접근 허용은 사용자의 명시적 승인이 필요합니다. 방문 기록을 저장하거나 외부로 전송하지 않습니다. Chrome이 표시하는 사이트 접근 권한은 선택한 주소의 상위 페이지 이동을 바꾸기 위한 권한입니다.

## 연결과 해제

- 앱을 먼저 열고 Chrome을 열면 자동 재연결합니다. 앱이 닫혔거나 일시정지·완료·휴식 상태면 차단하지 않습니다.
- 앱 설정의 **차단 끄기**, 확장 팝업의 **연결 해제**, 또는 Chrome 확장 관리에서 비활성화/삭제하면 해제할 수 있습니다.
- 강제 종료·연결 끊김에는 WebSocket 닫힘 또는 짧은 유효기간 만료로 해제합니다. OS 절전·브라우저 백그라운드 타이머 정지는 실제 Chrome에서 추가 확인해야 합니다.
- 연결 실패 시 앱이 열려 있는지와 코드가 현재 앱의 코드인지 확인합니다. 로컬 포트 42731이 다른 앱에서 사용 중이면 연결되지 않습니다.

## 처리하는 데이터

`127.0.0.1:42731`에만 연결합니다. 공유되는 값은 선택 도메인, 집중 중 여부, 만료 시각입니다. 작업명·기록·방문 URL은 전송하지 않습니다. 연결 코드는 확장의 로컬 저장소와 앱의 사용자 데이터 폴더에 보관됩니다. 서버나 시스템 프록시/hosts 파일은 사용하지 않습니다.

일반 Chrome 프로필에서 동작하며 시크릿 모드는 별도 권한이 없으면 적용되지 않습니다. Chrome 외의 앱·브라우저나 앱이 꺼져 있는 시간은 제한하지 않습니다.

## 현재 검증 범위

인증된 로컬 연결의 시작/일시정지/완료 정책과 선택·허용 도메인별 규칙 테스트가 통과했습니다. 실제 Chrome 확장 설치·권한 승인·사이트 이동은 Mac 잠금 때문에 아직 확인하지 못했습니다.
